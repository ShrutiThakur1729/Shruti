# The World Inside
### A little universe called Shruti

An early 3D exploration study built on React, TypeScript, Vite and React Three Fiber.

```sh
npm ci
npm run dev
npm test
npm run build
```

In environments that deny child processes used by Vite, use `npm run build:portable` and `npm run preview:portable`. This Rollup/TypeScript fallback runs without subprocesses and serves at http://127.0.0.1:4173. It is intentionally unminified for this development study.

Enter the world, dismiss the controls and click the landscape for pointer lock. WASD moves, Shift speeds up, E interacts near the journal/atlas, M opens the atlas, Escape releases the pointer/closes a panel. During cinematic travel, Space/Ctrl adjusts altitude. Meet Shruti and World atlas provide pointer-only alternatives.

Exactly four coordinate-linked destinations are present. Only the First Hello exploration study has introductory interactions. Other worlds are clearly labelled development destinations. This is not yet the finished cinematic environment.

See docs/ARCHITECTURE.md for the audit, systems and milestone status, and docs/ASSETS.md for provenance and missing art assets. Work stays on portfolio-four-worlds. No remote push until First Hello passes its full acceptance gates.

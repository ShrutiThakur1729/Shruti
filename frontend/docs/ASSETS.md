# Asset inventory and visual direction

## Reference direction
User supplied three reference images: a four-panel castle approach/grounds/entrance/hall study, an enchanted Gothic library, and a mountain lake with cliffside fortifications.
Translate their warm lighting, monumental Gothic scale, layered vegetation, stone routes, distant mountains and rich interior depth into original environments. They are references only; no film assets or external models have been copied.

## Currently used
- Terrain, terrace, arch stones, lanterns, trees, distant silhouette and map: original procedural development geometry in this repository. These are draft assets, not approved final hero assets.
- Cormorant Garamond and Manrope: Google Fonts CSS; SIL Open Font License, served by Google Fonts. System serif/sans fallbacks are supplied. Self-host and retain license notices before final delivery.
- Three.js / React / React Three Fiber / Drei: dependencies and transitive licenses retained in node_modules and lockfile; review distribution notices when final assets are packaged.
- No user reference images shipped as production textures.

## Missing for final First Hello
- Detailed original/licensed hero gate and welcome pavilion.
- Stone PBR materials, path edging, masonry detail and terrain blend textures.
- Multiple optimised foliage species with natural silhouettes and LODs.
- River banks, physically credible water, distant mountain meshes.
- Licensed ambient wind and environmental sound.
- Compressed texture/model pipeline with size and performance budgets.

## Later milestones
Garden discoveries; full castle exterior, grounds, monumental doors, great hall, gallery exhibits; animated readable books; open-world landmarks. Girl, dragon and hand gestures are explicitly deferred.
